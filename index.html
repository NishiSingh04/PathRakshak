ABOUT THE PROJECT

Technology with a human purpose.

PATHRAKSHAK is a road-safety project concept focused on making incident reporting and response information easier to organize. This version is a frontend prototype built with HTML, CSS, and JavaScript.

Future scope could include a secure backend, verified responder directory, maps, and tested integrations. Those capabilities are not part of this demo.
