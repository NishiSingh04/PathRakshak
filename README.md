### PathRakshak: AI-Powered Road Safety & Emergency Response System

PathRakshak is an intelligent web-based safety ecosystem designed to streamline accident reporting, calculate instantaneous incident risk metrics, and dynamically alert the nearest critical response facilities like police stations and hospitals. 

### 🚀 Core Features

• **Interactive Incident Dashboard:** A central monitoring hub for viewing safety zones, past reports, and system statuses.
• **Smart Accident Reporting Form:** An intuitive, multi-step dynamic interface designed to gather clean, high-utility data under high-stress conditions.
• **AI Risk Assessment Engine:** A structured evaluation model that analyzes situational context (e.g., impact level, time, weather) to compute an immediate severity score.
• **Automated Emergency Dispatch System:** An algorithmic routing layer designed to locate and dispatch critical incident data to the closest medical and law enforcement authorities. 

### 🛠️ Architecture & Tech Stack

• **Frontend UI:** HTML5, CSS3, JavaScript (Interactivity & State Management)
• **Database Layer (In-Development):** PostgreSQL for structured relational mapping of emergency nodes, hospitals, and incident reports.
• **Backend Core (Planned):** Java Spring Boot for high-throughput enterprise API integration, security filtering, and automated messaging alerts. 

### 📂 Project Repository Layout

• /assets - Visual collateral, iconography, and architectural diagrams.
• /css - Modular, responsive grid frameworks and custom design tokens.
• /js - Dynamic DOM manipulation logic and prototype risk calculators.
• dashboard.html - The core functional interface for emergency dispatchers and users.
• report.html - The intake portal hosting the strategic response questions.
